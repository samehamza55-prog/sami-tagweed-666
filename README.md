# بوابة نتائج دورة التجويد

نظام عربي خاص بنتائج الطلاب: دخول مستقل لكل طالب، ولوحة مسؤول، وإضافة اختبارات بلا حد عملي، وتعديل العلامات، وطباعة إفادة النتيجة.

## بيانات الدخول الأولية

**المسؤول**
- كلمة المرور: `Tajweed-26`
- غيّرها عند النشر في متغير البيئة `ADMIN_PASSWORD`.

**الطلاب**
| الطالب | اسم الدخول | كلمة المرور |
|---|---|---|
| إبراهيم عبد الماجد | student1 | Ibrahim-26 |
| آدم حمزة | student2 | Adam-26 |
| أحمد عادل | student3 | Ahmad-26 |
| يحيى وجدي | student4 | Yahya-26 |
| عبد الرحمن علاء | student5 | Abdul-26 |
| تيم | student6 | Taym-26 |

الاختبار الأول مضبوط من الصورة المرفقة، وتيم 5/10. أُبقيت علامة عبد الرحمن علاء 5/10 كما ظهرت في الصورة أيضاً. راجع الأسماء والعلامات قبل اعتمادها.

## تشغيل محلي
1. ثبّت Python 3.11 أو أحدث.
2. نفّذ `pip install -r requirements.txt`.
3. شغّل `python app.py`.
4. افتح `http://127.0.0.1:5000`.

## النشر على GitHub وRender
1. أنشئ مستودع GitHub جديداً وارفع جميع ملفات هذا المجلد.
2. في Render اختر **New + → Blueprint** ثم اربط مستودع GitHub.
3. سيقرأ Render ملف `render.yaml`. عند طلب `ADMIN_PASSWORD` أدخل كلمة مرور جديدة خاصة بك.
4. تأكد من وجود القرص الدائم `tajweed-data` على `/var/data` قبل إدخال النتائج الفعلية.
5. بعد اكتمال النشر يعطيك Render رابطاً من نوع `https://tajweed-results.onrender.com`.

## ملاحظات أمان مهمة
- لا تشارك كلمة مرور المسؤول مع الطلاب.
- غيّر كلمات مرور الطلاب بعد أول دخول إذا رغبت.
- قاعدة البيانات تحفظ على القرص الدائم في Render؛ لا تحذف القرص لأنه يحتوي بيانات النتائج.
- لا يوجد تسجيل عام للطلاب؛ الإضافة من لوحة المسؤول فقط.
- صورة التوقيع المرفقة موضوعة في صفحة الطباعة. لم يُرفق ختم منفصل، لذلك لا يوجد ختم مزيف.
